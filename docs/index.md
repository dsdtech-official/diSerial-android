# diSerial for Android

USB serial terminal with live charts, shortcuts, and exportable logs.

diSerial by DSD TECH brings the core serial debugging workflows from Windows and macOS to Android phones and tablets. Connect over USB to send and receive serial data, replay saved commands, plot incoming values, and record and export logs. The wide tablet layout keeps the terminal and shortcuts in view together.

## Serial terminal

Set the baud rate, data bits, stop bits, and parity. Send ASCII or HEX data with optional line endings, add a frame checksum to HEX messages, or repeat a send at a set interval. View received data as text or hexadecimal, with filters and auto-scroll.

## Shortcuts

Save a command from send history, organize it into a group, and replay the original bytes with one tap. Import and export shortcuts as JSON for reuse.

## Live visualization

Plot incoming serial data using a numeric-column (CSV), key-value, or custom binary parsing profile. Pause the plot, check the latest value on each channel, or use a sample to preview a custom profile.

## Recording and export

Record serial traffic locally, find sessions by date, and inspect individual frames. Export logs as TXT or CSV for troubleshooting or sharing test results.

USB serial features require an Android device with USB Host (OTG) support and a compatible single-port USB serial adapter. This first release connects over USB.
